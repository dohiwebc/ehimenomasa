# 愛媛の雅ちゃん リニューアル提案サイト

実店舗「愛媛の雅ちゃん」（愛媛県松山市）への提案用リニューアルサイトです。

## サイトの目的

予約数の増加だけを目的とせず、店舗の認知と印象を良くすることを最優先としています。

- 松山市駅から近く、利用しやすいこと
- 名物鶏料理が分かりやすいこと
- 仕事帰りや友人同士など、普段使いしやすい居酒屋であること
- その延長として宴会・歓送迎会にも対応できること
- 温かみがあり、活気のある地域店に見えること

## 使用技術

- HTML
- CSS
- JavaScript

フレームワーク、CMS、Bootstrap、Tailwind CSS、ビルド工程は使用していません。HTMLファイルを直接開いて確認できます。

## ローカルでの確認方法

1. このフォルダを任意の場所に配置します
2. `index.html` をブラウザで開きます
3. または、簡易サーバーを使う場合:

```bash
cd "愛媛の雅ちゃん"
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

公開先は未定です。GitHub Pages、Cloudflare Pages、一般的なレンタルサーバーのいずれでも、相対パス中心の構成のため公開しやすい想定です。

## 画像の取得元

画像は現行公式サイト（`https://ehimenomasa.com`）および関連ドメイン上に掲載されていた実写画像をローカルへ保存して使用しています。

- `assets/images/original/` … 取得した元画像
- `assets/images/site/` … サイト表示用（内容が分かる英語ファイル名へ整理）

ホットリンクは行っていません。AI生成画像や海外ストック写真は使用していません。

現行ロゴ（`logo-masachan.png`）は現行サイトのロゴをそのまま使用しています。

## 予約フォームについて

`reserve.html` / `takeout.html` のフォームは**仮実装**です。

送信ボタンを押しても実際の送信は行わず、次の案内を表示します。

> 現在は提案用サイトのため、フォーム送信機能は実装されていません。

## 外部予約URLの設定場所

`js/main.js` 内の定数を編集してください。

```js
var EXTERNAL_RESERVATION_URL = "";
```

未設定（空文字）の場合、外部予約ボタンは非表示になります。架空のURLは設定しないでください。

## SEO / robots について

提案段階のため、全ページに以下を設定しています。

```html
<meta name="robots" content="noindex, nofollow">
```

正式公開時には、この `noindex, nofollow` を外してください。
